¿Independientes, excluyentes o dependientes?

Tres formas de combinar condiciones — y cómo se ve cada una si fueran ríos.

1

Independientes

varios if seguidos
compuerta abierta compuerta cerrada cauce seco

Tres ríos separados, cada uno con su compuerta. Python revisa cada if por su cuenta: pueden abrirse varios a la vez, uno solo, o ninguno.

if hay_mensaje_nuevo == True:
    print("Tienes un mensaje sin leer.")

if bateria_baja == True:
    print("Queda poca batería.")

if hay_wifi_disponible == True:
    print("Hay wifi disponible.")
Se usa cuando las preguntas no tienen nada que ver entre sí. Que haya wifi no cambia si te queda batería.
2

Excluyentes

if / elif / else
por aquí pasó el agua quedó seco

Un solo río con desvíos en cadena. El primer desvío que se abre se lleva toda el agua, y los de más abajo quedan secos: ni siquiera se revisan.

if racha_dias_estudio >= 14:
    print("Racha de élite")
elif racha_dias_estudio >= 7:
    print("Buena constancia")
elif racha_dias_estudio >= 3:
    print("Vas tomando ritmo")
else:
    print("Recién empezando")
El orden decide. Si el desvío más ancho va primero, se lleva el agua de todos los demás y esas ramas nunca se alcanzan.
3

Una depende de la otra

if anidado
1ª compuerta: ¿tiene pase? 2ª compuerta: ¿le alcanza?

Un solo río con las compuertas una detrás de la otra. A la segunda solo le llega agua si la primera la dejó pasar: la segunda pregunta solo tiene sentido dentro de la primera.

if tiene_pase_escolar == True:
    print("Puedes subir con tu pase.")
else:
    if saldo_tarjeta >= 800:
        print("Puedes pagar el pasaje.")
    else:
        print("No te alcanza para el pasaje.")
Si las escribes como dos if sueltos, el saldo se pregunta siempre — incluso a quien ya subió con su pase.

Mira la diferencia con alguien que sí tiene pase escolar

✅ Anidado — como corresponde
1° desvío: ¿tiene pase? 2° desvío: ¿le alcanza? — sin agua

Se va por su desvío apenas muestra el pase. El cauce que lleva a la pregunta del saldo queda seco: esa pregunta nunca se hace.

❌ Dos if sueltos
río de arriba: ¿tiene pase? río de abajo: ¿le alcanza? — con agua igual

El saldo corre por su propio río, así que se pregunta igual. Al mismo pasajero que ya subió con su pase le preguntamos si le alcanza.

Antes de escribir, pregúntate:

¿Independientes? varios if ¿Excluyentes? elif ¿Una depende de la otra? anidado

Y cuando ya esté escrito, prueba el valor del borde: 14, 7, 3, 800. Ahí es donde los programas se rompen sin avisar.
