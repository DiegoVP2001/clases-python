# Skill: Lista de estudiantes del curso

## Propósito

Esta skill entrega la nómina oficial del curso para que ejercicios, evaluaciones y personajes narrativos usen nombres reales en lugar de nombres genéricos ("Javiera", "Camilo", "María").

El archivo fuente está en `lista-estudiantes.md`. Este SKILL.md actúa como guía de uso — la mayoría de los casos se resuelven con la sección "Primeros nombres únicos" del archivo fuente; abre el índice alfabético cuando necesites el nombre completo de un estudiante específico.

Cuando necesites identificar a qué estudiante real corresponde una cuenta de Google con apodo o nombre de fantasía (al revisar entregas de Colab/Classroom), consulta primero `alias-cuentas-conocidas.md` — evita repetir una investigación ya hecha.

---

## Cuándo usar esta skill

- Al diseñar ejercicios de clase y quieres personajes con nombres del curso real.
- Al generar evaluaciones personalizadas para un estudiante específico (como revisiones individuales).
- Al crear ejemplos narrativos para la Práctica Guiada o el Haz Ahora con personas del curso.
- Cuando `revisar-evaluacion` necesita la nómina para preparar submissions o generar feedback.
- Cuando Diego diga "usa nombres del curso", "ponle el nombre de un estudiante" o similar.
- Cuando revises entregas (notebooks, Classroom, Colab) y aparezcan nombres de cuenta con apodos o nombres de fantasía en vez del nombre real del estudiante — consulta `alias-cuentas-conocidas.md` antes de investigar desde cero.

**No uses esta skill** cuando Diego ya indicó nombres específicos para el ejercicio, o cuando los nombres de los personajes sean ficticios por decisión pedagógica.

---

## Cómo usar el archivo fuente

El archivo `lista-estudiantes.md` tiene cuatro secciones:

| Necesitas | Sección a abrir |
|---|---|
| Nombres para personajes en ejercicios (sin repetidos) | "Primeros nombres únicos" |
| Nombre completo de un estudiante | "Nómina completa" o "Índice alfabético" |
| Verificar si dos estudiantes tienen el mismo nombre | "Nombres repetidos — cómo diferenciar" |
| Lista ordenada para entregas o revisión | "Índice alfabético" |
| A qué estudiante real corresponde una cuenta con apodo/nombre de fantasía | `alias-cuentas-conocidas.md` (archivo aparte) |

## Reglas de uso

1. **No poner la lista completa en un ejercicio.** Elige 2-4 nombres representativos. Varía entre clases para que no sean siempre los mismos.
2. **Si el ejercicio involucra datos personales simulados** (notas, dinero, rendimiento), usar nombres ficticios o solo primer nombre + inicial del apellido.
3. **Respetar la grafía exacta.** El nombre es "Luckas" (con k), no "Lucas"; "Katalina" (con K), no "Catalina"; "Nacor" no es un error.
4. **No asumir género por el nombre** al diseñar ejercicios o escenarios. Los pronombres se omiten o se usan en neutro salvo que Diego indique lo contrario.
5. **Para evaluaciones personalizadas**, siempre verificar el nombre completo en el índice alfabético antes de escribirlo en el artefacto.
