# Plantillas de salida — La Clase que Soñamos

Plantillas extensas para entregar una planificación de clase completa o una revisión de una clase ya existente. Úsalas cuando el usuario pida el documento final, no durante el diseño paso a paso (para eso, ver `references/estructura-5-pasos.md`).
