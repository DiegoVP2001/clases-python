# Referencia exhaustiva — Temáticas recomendadas para Google Colab

Plantillas de actividad listas para adaptar al diseñar un Colab completo. Cada una incluye contenido Python sugerido, ejemplo de consigna y posibles extensiones.

Consulta esta referencia cuando necesites variedad de propuestas de actividad para una clase o ayudantía completa — para contextualizar un solo ejercicio puntual, el resumen del `SKILL.md` suele bastar.

**Contenido Python sugerido:**

- variables;
- listas;
- condicionales;
- `input()`;
- `print()`.

**Ejemplo de consigna:**

> Crea un programa que pregunte el estado de ánimo del usuario y recomiende una canción o playlist.

**Extensión posible:**

- agregar géneros;
- agregar artistas;
- contar canciones;
- permitir que el usuario agregue una canción.
